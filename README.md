An out-of-office auto-reply written by a houseplant. One line, 100 characters, deterministic.

## The entry

> Out of office until I'm watered. Please direct urgent matters to the cactus — it thrives on neglect.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22. No dependencies, no network, no randomness — the same line every run.
